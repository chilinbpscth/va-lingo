# 藝言堂：小二／小五專業審核與改版建議

2026-09-14。已完成本地互動預覽；未接Google名冊、未部署，不能當作已完成正式學生登入。原repo主程式及Google v5保留。

## 核心判斷

評賞工具首先要降低操作及書寫負擔，同時留下可判讀的觀察。學段只決定預設支援與要求，不代表每名學生能力相同。KS1/KS2不由學生自行切換；登入年級自動設定，提示可隨時開啟。能力以回應內容及所需支援判讀，不以字數或深詞推算。

整體感受不評對錯，也不強迫每人落針。可以對整件作品有感受，亦可以未有特別感覺。小二先完成感受表達，指位置及說原因作延伸；小五用簡短原因把所見和感受相連。教師可確認口頭回應，不能把未輸入文字當作沒有能力。預覽的完成提示只是輸入檢查，不是質素評分。

## 要更新的地方（優先次序）

1. 登入模式同步：已重現小四仍留KS1，恢復後0/5，轉KS2才5/5。正式整合先修此項，保留原草稿/答案，不用遷移時覆寫掩飾。
2. 班別及學號改下拉：校內Google閘後只回傳有效班別及學號，切班重置學號，保留01前導零。不要假設每班固定30/40人，名單由私有Sheet決定，不輸出姓名。班別/學號是身分選擇，不能單靠知道號碼就宣稱核實本人。
3. 課堂編號留後端：學生登入後列自己的可用課堂。只有一堂直接進；多堂用課題＋學段＋狀態卡片揀；沒有課堂清楚提示老師安排。closed只讀。不能單憑前端年級選單取得其他班課堂。
4. 改五步學習提示：感受詞只在第一步；第二步說所見；第三步解釋特徵與效果；第四步提出有依據的可能理解；第五步以特徵支持回應。刪除所有課題硬套香港／鳥瞰／水墨的句式，立體/表演作品亦適用。
5. 初次用界面只留課題、作品、當前步驟與下一步；技術課堂碼、KS切換、重複提交按鈕收起。保留手動更新，但在互評開放前給準確提示，刪「即時作品」「加入課堂畫廊」舊文案。登入/取回要顯示進行中，成功後清除舊錯誤。
6. 名作圖與標題必須一致：沒有對應圖片就明確缺圖，不用其他作品示意圖填位。標示作者、名稱、館藏、圖片來源；放大圖及替代文字可讀。作品資料和學生詮釋分開。
7. 分開自評與互評：第一步自評問「睇返作品感到甚麼」；創作意圖另外問，不當作看圖感受。互評依據對方作品，不強迫稱讚或猜測作者心情。

## Google整合工單（未在此預覽實作）

- loginOptions：在校內Google閘內讀roster_v1，回classIds及每班studentIds；不回姓名。保留roster.school.json禁止提交規則。
- login：既有classId/studentId核名冊後回token、schoolYear、grade；前端據grade選支援模式，不能由學生更改服務端範圍。

- 評賞資料加schemaVersion；feel存感受文字陣列、理由、可選位置/整件範圍。舊mood/scaffold/open/pins讀回需兼容，原記錄保留；舊KS1強制emoji完成度不可直接沿用。
- 口頭回應狀態只由教師核實，不給學生一鍵假裝已說；與文字回應並列，不自動換算能力分。
- 驗收：選班重置學號；錯誤/過期token拒絕；無課堂/單堂/多堂；其他班不出現；模式與年級同步；舊答案恢復；仍需手動refresh互評。
